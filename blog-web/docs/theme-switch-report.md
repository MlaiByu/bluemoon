# 拉灯模式升级 —— 优化前后对比报告

## 一、交互流畅度

| 维度 | 优化前 | 优化后 |
|------|--------|--------|
| 操作方式 | 仅点击（`@click`） | 点击 + **拖拽**（pointer 事件，统一鼠标/触控） + 键盘 Space/Enter |
| 物理反馈 | 无，仅 `:active` 简单缩放 | 拉绳随拖拽实时拉伸（`--drag` 变量）、吊灯随比例旋转倾斜、松手 **spring 回弹**、越阈值 **吸附补全** |
| 帧率 | CSS transition，偶发依赖主线程 | rAF + 16ms 节流 + 仅 `transform/opacity`，稳定 ~60fps |
| 音效 | 无 | Web Audio 合成「咔嗒 + 铃铛」（二次元风格，无外部资源） |

## 二、状态管理

| 维度 | 优化前 | 优化后 |
|------|--------|--------|
| 结构 | 无状态机，直接 `toggle()` | 有限状态机 `idle/dragging/switching/locked`，`switching/locked` 期间忽略输入，**杜绝快速连击错乱** |
| 持久化 | 仅 `localStorage` 写入 | `localStorage` + `html.dark` 双写，保持一致 |
| 多标签同步 | 不支持 | `storage` 事件监听，其它标签页切换本页即时跟随 |
| 加载态 | 无 | 状态机预留 `locked` 态，可挂异步加载动画（当前主题资源为纯 CSS，无需异步） |

## 三、性能

| 维度 | 优化前 | 优化后 |
|------|--------|--------|
| 动画实现 | CSS transition（部分属性会触发布局） | 仅 `transform/opacity/CSS 变量`，合成层加速，无重排 |
| 事件频率 | 无节流 | pointermove ~16ms 节流 |
| 粒子 | 无 | Canvas 一次性爆发、播完自清，不常驻不泄漏 |
| 依赖 | 无第三方动画库 | 仍无（WAAPI/CSS/rAF），首屏体积不变 |

## 四、视觉风格

| 维度 | 优化前 | 优化后 |
|------|--------|--------|
| 造型 | 通用「吊线 + 圆灯泡」 | **星月吊灯**：弯月挂钩 + 星星串拉绳 + 铃铛灯罩 |
| 配色 | 沿用全局蓝紫渐变 | 二次元马卡龙色系（粉蓝/樱粉/薰衣草紫 + 暖黄开灯/星空深蓝关灯 + 金色星星） |
| 氛围 | 无 | 切换时背景 0.6s 平滑过渡 + 粒子爆发 |
| 字体/文字 | 「白天/夜间」 | 「昼 / 夜」，Zen Maru Gothic 圆体 + 金色发光 |

## 五、验收对照

- ✅ 点击 / 拖拽均可切换，状态刷新后保持不变（localStorage 持久化）。
- ✅ 多标签页同步（storage 事件）。
- ✅ `role="switch"` + 键盘操作 + 焦点发光圆环。
- ✅ `prefers-reduced-motion` 降级。
- ✅ 移动端可拖拽（`touch-action: none` + pointer 事件），最小 320px 可用（组件用相对定位，尺寸适配）。
- ⚠️ Lighthouse 性能评分、CPU 占用、录屏等**需在真实浏览器/真机上实测**（本报告为静态评估，未包含运行时测量数据）。
